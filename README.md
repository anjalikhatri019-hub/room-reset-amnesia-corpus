# Room Reset Amnesia Corpus v3.1

Download the participant dataset from the [v3.1.0 release](https://github.com/anjalikhatri019-hub/room-reset-amnesia-corpus/releases/tag/v3.1.0). Upload that release's `room_reset_public.zip` as the raw Dataset ZIP. Its 4,003 members contain public observations, training answers, indexes, and a dataset card. There is no private test answer file in this archive.

The corpus has 2,000 creator-generated simulated room episodes: 1,600 labeled training cases and 400 unlabeled test cases. Each case has 16 grayscale frames of a 64-object room, plus visibility and rotation metadata. A shared, unknown camera shutter changes the displayed object textures after a reset. The dataset card documents the schema, split, generation assumptions, and limits. No real photographs, people, or clinical observations were used.

The participant ZIP is 528,744,998 bytes. SHA-256: `215c3151614dffce3b928652b7b9ce912a92788dfac534dc6bea558acfb319e4`.

The creator-generated dataset is offered under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Organizer test answers are derived privately after dataset validation by the challenge Prepare script.

The [v3.0.0 release](https://github.com/anjalikhatri019-hub/room-reset-amnesia-corpus/releases/tag/v3.0.0) remains available for provenance; use v3.1.0 for the current challenge.
