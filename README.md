# Room Reset Amnesia Corpus v3

This repository is the public source page for the participant-safe Room Reset Amnesia dataset. Download `room_reset_public.zip` from the [v3.0.0 release](https://github.com/anjalikhatri019-hub/room-reset-amnesia-corpus/releases/tag/v3.0.0). The archive contains 2,000 creator-generated simulated room episodes: 1,600 labeled training cases and 400 unlabeled test cases. No real photographs, people, or clinical observations were used.

Each case has 16 grayscale frames of a 64-object room, plus visibility and rotation metadata. A shared, unknown camera shutter changes the displayed object textures after a reset. The dataset card inside the ZIP documents the schema, split, generation assumptions, and limits.

The participant archive is 528,743,623 bytes. SHA-256: `07b0780693878deccb010cc29f39b376d6c7877704258f64d1f479292b0ff959`.

The creator-generated dataset is offered under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). This release contains public observations and training answers only. Organizer-only test answers, generator seed, and reference solution are excluded.
